# Feature Roadmap

## Implemented

1. Currency converter history
   - Save recent conversions.
   - Show amount, source currency, target currency, converted value, and time.
   - Let users quickly reuse a past conversion.

2. Favorite currency pairs
   - Save common pairs such as USD/PKR, EUR/USD, and BTC/USDT.
   - Show favorites on the converter screen for one-tap switching.
   - Allow removing saved pairs.

3. Offline last rates
   - Cache the most recent successful exchange rates.
   - Use cached rates when the network is unavailable.
   - Show the last updated date clearly.

4. Swap and quick amount chips
   - Add quick amount buttons such as 10, 50, 100, and 1000.
   - Keep the existing swap action easy to reach.

5. Rate alert
   - Let users create simple target alerts.
   - Support alerts for fiat pairs and crypto prices.
   - Store alerts locally until push notifications are added.

## Ready To Implement

7. Better crypto detail screen
   - Show TradingView chart plus price, 24h high/low, market cap, volume, and rank.
   - Keep detail content readable on mobile.

8. Search and filters on Crypto Prices
   - Add filters for top gainers, top losers, market cap rank, and favorites only.
   - Keep the current search bar.

9. Portfolio tracker
   - Let users enter holdings such as 0.5 BTC or 10 ETH.
   - Show total estimated value in the selected fiat currency.

10. Dark/light theme toggle
   - Add a theme switch in Settings.
   - Save the preference locally.

11. Home dashboard
   - Show favorite pairs, top crypto movers, last conversion, and quick convert.
   - Use this as a useful first screen instead of a plain landing area.

12. Multi-currency comparison
   - Convert one amount into multiple selected currencies at once.
   - Let users manage the comparison currency list.

13. Better empty/loading/error states
   - Add retry buttons where API calls fail.
   - Show cached data when fresh data cannot load.

## Backlog

6. Chart inside converter
   - Add a mini 7-day or 30-day chart for the selected currency pair.

14. Push notifications
   - Send alerts for target rates, favorite coin movement, and daily summaries.

15. Share conversion result
   - Let users share conversion output through the platform share sheet.
